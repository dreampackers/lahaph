# Lahaph WordPress Project

This repository contains the official website project for Lahaph.

## Structure
- `wp-content/themes/lahaph-theme` : custom WordPress block theme
- `wp-content/plugins/` : custom plugins
- `docs/` : planning, architecture, content, and QA documents
- `CLAUDE.md` : core project rules for Claude Code

## Workflow
1. Read `CLAUDE.md`
2. Read all files in `docs/`
3. Implement plugin architecture first
4. Implement theme architecture second
5. Connect content and templates
6. Run QA before release
