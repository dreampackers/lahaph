# Design System

## Brand Personality
- Warm
- Artistic
- Trustworthy
- Clear
- Human-centered

## Color Palette
- Primary Green: #46C449
- Warm Yellow: #E2A21A
- Soft Gray: #9EA0A3
- Sky Blue: #62C7E8
- Deep Navy: #1E2F6F
- Coral Red: #B53322
- Purple Accent: #6F4B8B
- Olive Gold: #8C8A37
- Black: #222222
- White: #FFFFFF

## Usage
- Primary CTA: Primary Green
- Headings: Deep Navy
- Body text: #222222
- Section backgrounds: White or very light tinted neutral
- Use accent colors sparingly

## Typography
- Prioritize readability
- Clear heading hierarchy
- Avoid narrow line-length issues
- Mobile-first spacing

## UI Style
- Rounded cards
- Clear section spacing
- Large CTA blocks
- Modular grid layout
- Avoid clutter
