# Design System

## Brand Keywords
- Warm
- Hopeful
- Trustworthy
- Artistic
- Human-centered
- Readable

## Color Palette
- Primary Green: #46C449
- Warm Yellow: #E2A21A
- Soft Gray: #9EA0A3
- Sky Blue: #62C7E8
- Deep Navy: #1E2F6F
- Coral Red: #B53322
- Purple Accent: #6F4B8B
- Olive Gold: #8C8A37
- Black: #222222
- White: #FFFFFF

## Usage Principles
- Primary CTA uses Primary Green
- Titles and strong information use Deep Navy
- Body text uses Black
- Background should mostly stay White or very light neutral
- Accent colors should be used carefully, not all at once

## Typography
- Readable and calm
- Strong heading hierarchy
- Comfortable line spacing
- Mobile-first readability

## Component Style
- Rounded cards
- Soft spacing
- Strong section separation
- Image-led but text-readable
- Clear CTA areas

## Avoid
- overly decorative effects
- cluttered home page
- low contrast combinations
- overly dark UI
