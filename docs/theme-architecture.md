# Theme Architecture

## Theme Name
lahaph-theme

## Theme Type
Custom WordPress block theme

## Theme Responsibilities
- global design system
- block theme templates
- template parts
- block patterns
- archive and single layout rendering
- page presentation
- typography, spacing, colors
- responsive layout

## Required Theme Files
- style.css
- theme.json
- functions.php
- templates/
- parts/
- patterns/
- assets/
- inc/

## Suggested Template Files
### Core
- templates/index.html
- templates/front-page.html
- templates/page.html
- templates/single.html
- templates/archive.html
- templates/search.html
- templates/404.html

### Custom Templates / Specialized Layouts
- templates/archive-musical.html
- templates/single-musical.html
- templates/archive-notice.html
- templates/single-notice.html
- templates/archive-disclosure.html
- templates/single-disclosure.html

## Template Parts
- parts/header.html
- parts/footer.html
- parts/page-hero.html

## Block Patterns to Create
- Hero section
- Intro text section
- CTA section
- Timeline section
- Profile card grid
- Poster grid
- Program card grid
- Contact section
- Download section
- Section heading + summary

## Theme Design Direction
- clean and warm nonprofit style
- trustworthy and readable
- not generic corporate
- not experimental
- suitable for parents exploring educational and arts content

## theme.json Goals
- define brand colors
- define typography scale
- define spacing presets
- define button styles
- define layout widths
- define block defaults where useful
