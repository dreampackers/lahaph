# Copy Guidelines

## Tone
- Warm
- Clear
- Trustworthy
- Professional
- Parent-friendly

## Writing Rules
- Use short paragraphs
- Avoid jargon when possible
- Focus on benefits and clarity
- Use section headings aggressively
- Reformat source content for web readability

## CTA Patterns
- 문의하기
- 상담 신청하기
- 과정 자세히 보기
- 공연 자세히 보기
- 모집요강 다운로드
